# Security policy

## Supported version

The `main` branch is the supported development version of Game School.

## Reporting a vulnerability

Please do not post security-sensitive findings in a public issue. Contact the repository owner privately with a concise description, affected path or feature, reproduction steps, and the potential learner impact. Allow time for investigation before public disclosure.

## Privacy boundary

Game School is designed as a local-first experience. New features must not introduce analytics, advertising, account collection, or third-party learner-data transmission without a documented privacy and safeguarding review.
